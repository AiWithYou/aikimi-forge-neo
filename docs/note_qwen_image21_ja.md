# Qwen Image 2.1をAikimi Forge Neoに実装しました

画像を作ったあと、「机の上のこの小物だけ消したい」と思ったことはありませんか。Aikimi Forge Neoに追加した**Qwen Image 2.1専用タブ**で、実際にひとつ編集してみました。ここでは操作画面と出力をそのまま見せます。

## 赤く囲んだ切符と台座を消してみる

元画像は、海を望む室内で銀髪の人物が小さなキャラクターを抱いているイラスト。机の右下にある「おひるね便」の切符と金色の台座を消したい、という設定です。

上部の「Qwen Image 2.1」タブを開き、画像を参照画像として追加します。1枚なら描画欄が開くので、対象を赤いペンで囲みました。右のプロンプトには「赤い囲みの中の『おひるね便』の切符と金色の台座を消し、机の木目で自然に埋めてください」と入力。人物、眠っている子、トレー、カップ、海はそのまま残すようにも指示しています。

![Qwen Image 2.1の実際の編集画面。左に赤い囲み付きの参照画像、右に指示と生成設定](./assets/qwen-image21-note/webui-edit.jpg)

*2026年9月21日の実画面。左で編集箇所を囲み、右で指示と設定を確認します。スクリーンショットはモデル読み込み中の状態です。*

この回の設定は**INT8・CPU退避・1024×1280・40 steps・Seed 92113**。約858秒かかったのは、保存済みモデルの読込ではなく、公式重みからINT8に変換しながらの読込です。画像生成処理は約96秒。モデルをメモリに保持して同条件で再実行したときは、再読込なしで生成処理が約92秒でした。

変換後のモデルを保存しても、次回起動時の読込は必要です。保存済みINT8を読み込んだ別の試行は約448秒でした。いずれもRTX 3090（24GB）での実測で、保存先や環境によって変わります。

![切符と台座を赤く囲んだ入力画像と、それらを消した生成結果の比較](./assets/qwen-image21-note/sign-before-after.jpg)

*左が赤枠を描いた入力、右がモデルの出力。比較用の台紙を付け、両画像を縮小して並べています。生成された部分には加筆していません。*

切符と台座は消え、そこに机の木目がつながりました。拡大しても、対象の跡はかなり自然です。一方、囲みはモデルに場所を教える**注釈**です。人物や背景は似た状態を保っていますが、囲みの外の細部まで元画像と同じ画素になるわけではありません。

![切符と台座があった場所を同じ座標で拡大した比較](./assets/qwen-image21-note/sign-detail.jpg)

*同じ座標を拡大した比較。右側の木目はQwen Image 2.1の生成結果です。*

画面の「この画像を続けて編集」を押せば、結果を次の編集元として開けます。作り直したい箇所を見つけたら、そのまま次の指示へ進める流れにしています。

## 背景を画素単位で残したいなら、マスクを使う

囲みだけで対象外が完全に保たれると誤解しやすかったので、**「マスク範囲外を元画像に固定」**も加えました。こちらは変更したい部分をマスクで塗り、生成後にその部分だけを元画像へ合成する機能です。囲み注釈と併用できますが、役割は別です。

別の実例として、ロボットの横にある赤いカップだけを青くしました。編集元と出力を同じ1024×1024にし、カップを含む領域をマスク。PE-I2Iの指示補助をONにして、W4A8・CPU退避・40 stepsで1回生成しています。

![白いロボットと赤いカップの編集元画像](https://raw.githubusercontent.com/AiWithYou/aikimi-forge-neo/neo/docs/assets/qwen-image21-v1.3.0/int8.png)

*編集元。これは同じタブで生成した画像です。*

![Qwen Image 2.1が生成した、青いカップの全体画像](https://raw.githubusercontent.com/AiWithYou/aikimi-forge-neo/neo/docs/assets/qwen-image21-v1.4.0/model-generated.png)

*モデルの出力そのまま。カップは青くなりましたが、ロボットや背景の細部にも変化があります。*

![マスク外を元画像に固定した青いカップの結果](https://raw.githubusercontent.com/AiWithYou/aikimi-forge-neo/neo/docs/assets/qwen-image21-v1.4.0/mask-preserved.png)

*マスク外を固定した出力。カップ周辺以外は元画像の画素を残しました。*

この試行では、**マスク外の937,341画素のRGBA値が元画像と完全一致**しました。生成画像と固定版の両方を保存するので、「モデルがどう描いたか」と「どこを残したか」を見比べられます。ただし、マスク境界の仕上がりと編集部分の自然さは画像ごとに確認が必要です。ここで示すのは1枚の実例です。

## 使い始めるには

Neoを終了し、リポジトリの`aikimi-qwen-image21-setup.bat`を実行します。普段どおり`aikimi-launch.bat`で起動したら、上部の「Qwen Image 2.1」タブへ。まずは**INT8・CPU退避・1024×1024・40 steps**で、新規生成か1枚の参照編集を試すのがおすすめです。参照なしなら文章から新規生成、画像を追加すると編集になります。

参照画像は最大10枚。生成した画像を次の編集元にする操作のほか、透過背景の指示、INT8／W4A8／BF16の切り替え、文章用PE-T2Iと編集用PE-I2Iも用意しています。追加機能の条件と操作は[機能ガイド](https://github.com/AiWithYou/aikimi-forge-neo/blob/neo/extensions-builtin/qwen-image21-studio/README.md)にまとめました。

今回の実機はWindows 11、RTX 3090 24GBです。公式モデル一式に約33GB、別途専用のPython環境用の空き容量が必要です。2Kの参照編集も確認していますが、その試行ではGPU総使用量が約23.4GiBに達しました。最初は1024角で動作を確かめるのが現実的です。

このタブはQwen Image 2.1の公式Diffusersパイプラインを使います。Forge本体のLoRA、ControlNet、追加スクリプトをそのまま接続する機能ではありません。モデル重みは**Qwen Research License**で、研究・評価目的の非商用利用に限られます。利用前に[公式ライセンス](https://github.com/QwenLM/Qwen-Image-2.1/blob/main/LICENSE)を確認してください（2026年9月23日確認）。

画像を読み込み、気になる箇所を囲み、結果を見て次の編集に進む。元画像を厳密に残したい場面ではマスクへ切り替える。Qwen Image 2.1をNeoの中で、こうした手順で使えるようにしました。
