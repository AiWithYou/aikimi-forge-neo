# Jev / Sparse Attention 実機比較

確認日: 2026-09-21。RTX 3090 24GB、Windows、PyTorch 2.11.0+cu130。生成画像の完全一致は合格条件にしていません。プロンプトへの適合、見た目の破綻と生成全体の時間を確認します。

## 速度優先版

Jevは1回だけ問い合わせ、その後は観測用の追加計算も止めます。画像モデルの保持率は25/50/75/100%。判断目的を速度優先にし、有効な回答を信頼度だけで100%へ変更する処理を外しました。APIエラーや不正回答の退避は維持しています。原回答・信頼度・実際の適用率を別々に記録します。

各方式を同じ入力・seed・stepsで2回測り、実行順を反転しています。モデルを保持し、ウォームアップを除いた中央値を使います。比較は1プロンプト・1 seedの小規模な実測です。

### Anima 3.8B v1.1

INT8 ConvRot、1024×1024、32 steps、Res Multistep / Beta、CFG 4、shift 3、seed 20260921。Jev SDK 0.7.0 / jev-1.13.0、comfy-kitchen 0.2.33。

| 方式 | 総時間の中央値 | API回数/生成 |
|---|---:|---:|
| 通常OFF | 44.04秒 | 0 |
| 固定25% | 38.23秒 | 0 |
| 数値ルール | 41.69秒 | 0 |
| Jev速度優先 | 41.30秒 | 1 |

Jevの52層の回答は25%が13層、50%が27層、75%が11層、100%が1層でした。2回とも原回答と適用値は一致し、最小信頼度は0.35。旧0.3閾値を下回る回答はありませんでした。今回の応答で機械的な100%補正は起きていません。

Jev版では銀髪の人物・望遠鏡・天体という主要な要素を維持した画像を確認しました。固定25%は速い一方、2人の構図になる例がありました。画像の相違自体を失敗判定には使っていません。生成物と生の記録は `outputs/jev-benchmark-20260921/anima-speed` に保存しています。

### Qwen Image 2.1

W4A8、GPU配置、1024×1024、20 steps、seed 20260921。Qwen専用環境のcomfy-kitchenは0.2.31を維持しています。

| 方式 | 総時間の中央値 | API回数/生成 |
|---|---:|---:|
| 通常OFF | 15.69秒 | 0 |
| 固定25% | 16.68秒 | 0 |
| Jev速度優先 | 21.08秒 | 1 |

Jevの32層の回答は、1回目が25%×7・50%×19・75%×5・100%×1、2回目が25%×6・50%×21・75%×3・100%×2。原回答と適用値は一致し、Sparse実行も589回・570回を記録しました。API待ちは2.08秒・1.64秒です。

この条件ではOFFが最速です。APIを使わない固定25%もOFFより遅いため、API待ちだけが原因ではありません。生成画像の見た目では固定25%に物体の繰り返し、Jev版にも配置や枚数の変化があります。画像が一致するかどうかを速度の合格基準にはしていません。記録とPNGは `outputs/jev-benchmark-20260921/qwen21-speed` に保存しています。

### H3

Fused Turbo INT8 ConvRot、INT8 Video VAE、864×480、5秒指定（124 frames / 24 fps）、4 steps / res_multistep、seed 20260921。64GB RAM環境のRAM保持プロファイルとCLIP自動キャッシュを全方式で併用しています。

| 方式 | 総時間の中央値 | samplingのみ | API回数/生成 |
|---|---:|---:|---:|
| Dense比較 | 47.21秒 | 27.50秒 | 0 |
| 固定SLA 5% | 38.67秒 | 19.31秒 | 0 |
| 固定SLA 10% | 39.15秒 | 19.69秒 | 0 |
| Jev速度優先 | 40.70秒 | 21.25秒 | 1 |

JevはDense比で約13.8%、固定5%は約18.1%短縮しました。速度だけなら今回の最短は固定5%です。JevのAPI待ちは平均2.06秒で、sampling時間にも総時間にも含めています。Jev・固定とも各生成でnative SLA producerを200回実行しました。

Jevは最初のステップを固定5%で実行し、その観測から残り3ステップの保持率を1/3/5/10%から選びました。層0は5%固定、残り49層の原回答は1回目が1%×10・3%×20・5%×15・10%×4、2回目が1%×10・3%×15・5%×20・10%×4でした。

雨の中庭、赤い紙の舟、水面の波紋を確認しました。映像はH.264、音声はAACで、全デコードで124 video frames / 162 audio framesを確認しています。記録・動画・確認用フレームは `outputs/jev-benchmark-20260921/h3-speed-cached` に保存しました。

モデル読み込みと最初のCLIPキャッシュ作成を含むウォームアップ全体は約18分19秒でした。表は同じプロンプトでキャッシュを再利用した後の値です。キャッシュにないプロンプトでは文章の再処理が必要です。RAM保持とCLIP自動キャッシュの組み合わせにより、大きなテキストモデルを処理後に解放して連続生成しました。途中で中止したPinned Memory版と、CLIPなしでメモリ不足になった試行は集計に含めていません。

モデルはMATLOWAI/minimax-h3-fused-turbo-int8-convrotの `8a8dffaa0cd99c6184833ae0a3b4e9b0089c17b3`。20,980,178,976 bytes、SHA-256 `4262e4e9963c553fa00016bbe83961407a4fc0a888be95fd836c8d4f2304e48b` を配布元の情報と照合しました。

## 旧保守設定の参考記録

初期コードは「不確かなら100%」と指示し、さらに信頼度0.3未満を100%へ戻していました。原回答の記録がなかったため、当時の100%がどちらで決まったかはログだけでは判別できません。以下は現在の速度優先版の結果ではありません。

| 対象 | 通常OFF | 固定75% | Jev旧設定・最大4回 |
|---|---:|---:|---:|
| Qwen 2.1 | 21.77秒 | 28.94秒 | 30.34秒 |
| Anima 3.8B v1.1 | 44.56秒 | 41.06秒 | 53.30秒 |

この旧設定でのJev実行は全層Denseでした。Qwenの固定Sparseはblock-gather + SDPAであり、native SLAと同じ性能特性ではありません。ブロック選択・取り出し処理の負担も含めて評価します。
