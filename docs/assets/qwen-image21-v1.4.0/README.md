# v1.4.0：マスク外を固定したQwen編集

PE-I2Iのプロンプト補助、保存済みW4A8モデル、Sparse固定75%、明示マスクを組み合わせた1例です。赤いカップを青くし、マスク外のロボットと背景は元の画素を残しています。

| 元画像 | マスク外を固定した結果 |
|---|---|
| ![元の赤いカップ](../qwen-image21-v1.3.0/int8.png) | ![マスク外を固定して青くしたカップ](mask-preserved.png) |

[モデルが生成した全体画像](model-generated.png)も保存しています。全体画像では細部や背景にも変化があります。固定版は、元画像・生成画像・明示マスクを同じ座標で合成した結果です。マスク外937,341画素のRGBAは、元画像と完全一致しました。境界のぼかしはマスクの内側だけに適用します。

## 条件と測定

- 2026年9月22日、Windows 11、RTX 3090 24GB、PyTorch 2.11.0+cu130。
- Qwen Image 2.1、W4A8、CPU退避、1024×1024、40 steps、Seed 9212027。
- PE-I2IはNF4二重量子化でON。VisionはBF16。元の指示と使用した文章は[測定値](measurements.json)に記録しています。
- Sparseは固定75%、4ブロック単位でまとめる設定。外部API呼び出しは0回です。
- 編集マスクはカップを含む領域、内側4pxのぼかし。モデルが生成したRGBAも固定版も保存しています。

| 項目 | この試行の結果 |
|---|---:|
| PE-I2I読み込み＋書き換え | 31.014秒 |
| 保存済みW4A8の読み込み | 307.153秒 |
| プロンプト・参照処理＋生成＋画像変換 | 75.485秒 |
| 実Sparse呼び出し | 1,248回 |
| 元画像と完全一致したマスク外画素 | 937,341画素 |

両コンポーネントは保存済みの量子化モデルを使用し、この実行では再変換していません。モデルはUSB接続SSDに置いており、読み込みはディスクキャッシュ状態にも左右されます。これは編集機能を組み合わせた確認で、通常生成との速度比較や、全題材での画質評価ではありません。

元画像は[v1.3.0の公開比較](../qwen-image21-v1.3.0/README.md)のINT8生成画像です。加工した評価画像と測定値を掲載し、モデル重みは同梱していません。実装全体と検証範囲は[更新記録](../../optimization-persistence-2026-09-22.md)を参照してください。
