# Irodori TTS

Irodori-TTS-v4-Largeで日本語の音声を生成します。読み上げ文だけでも、声の説明や参照音声を加えても生成できます。

## 準備

リポジトリ直下の`aikimi-irodori-setup.bat`を実行してからForge Neoを起動し、`Irodori TTS`タブを開きます。Python 3.11の専用環境へ公式コードと依存関係を導入し、モデル・tokenizer・DACVAE・SilentCipherを取得します。必要なPythonはuvで取得します。Forge本体のPython環境は更新しません。NVIDIA CUDA GPU向けです。

独自に学習したv4-Large互換の本体は、単一の`.safetensors`を`models/Irodori-TTS/v4-Large/checkpoints/`の直下へ置き、「モデル」欄の一覧を更新して選択します。このフォルダーはForge Neoの起動時に用意されます。この場所の本体は、導入済みの公式v4-Large tokenizerとDACVAEを共有します。異なるtokenizerやcodecを必要とするモデルには対応しません。必須の設定メタデータと全テンソルの構造を確認し、互換性を確認できない本体やLoRAだけのファイルは拒否します。実行環境と共通部品が揃っていれば、公式本体がなくても独自本体を使用できます。公式本体へ戻す場合は「公式 v4-Large」を選びます。

通常の浮動小数点本体と、公式torchao形式のINT8 weight-only（W8A16）、INT8 dynamic（W8A8）、INT4 weight-only（W4A16）、FP8 weight-only／dynamicを選択できます。量子化本体の計算精度はBF16です。INT4にはCUDAのCompute Capability 8.0以上が必要で、INT4 weight-onlyはW4A8ではありません。

[公式モデルカード](https://huggingface.co/Aratako/Irodori-TTS-v4-Large-Quantized)はFP8の両方式にCompute Capability 8.9以上を案内しています。Forge NeoではFP8 weight-onlyに限り、CUDAとBF16に対応するGPUでも選択できます。固定環境のRTX 3090（8.6）では、公式FP8 weight-only本体による短い音声生成を確認しています。FP8 dynamicには8.9以上が必要です。形式やGPUの条件が合わない場合、別の本体へ自動で切り替えずエラーにします。

## 使い方

1. 初回は「モデル」で公式または独自本体を選択し、内容の確認が終わるまで待ちます。
2. 日本語の読み上げ文を入力します。公式の感情・発声用絵文字もそのまま使用できます。
3. 必要なら「声の説明」に声質・感情・話し方を入力します。空欄でも生成できます。
4. 声を参照したい場合は「参照音声」を開き、使用許可のある同じ話者の音声を追加します。参照なしでも生成できます。
5. 「生成」を押し、完成した音声を再生・保存します。「中断」は停止確認後に次の生成を受け付けます。

参照は16/24/32bit PCM WAVに対応します。最大12ファイル、合計120秒までです。複数の参照は順番に別々にエンコードして結合します。公式は同じ話者の短い音声を複数使う方法を推奨しています。参照と声質の指示が矛盾する場合は、声の説明を感情や話し方に絞ってください。

詳細設定の標準値は40ステップ、テキストCFG 3、声の説明CFG 3、参照音声CFG 5です。BF16を標準とし、FP32も選べます。これは量子化設定ではありません。音声codecはFP32で動作します。長さ0は自動予測です。長さ倍率は自動予測だけに適用します。指定した長さから末尾の無音が除かれるため、完成ファイルの秒数が短くなる場合があります。

## 保存と制限

出力は`outputs/irodori/<生成ID>/`に48kHz WAV、生成条件、結果情報として保存します。このセッションの履歴から再生・ダウンロードできます。条件には実際のseed、本体名・SHA-256・保存形式、コードと共通codecのrevision、参照音声のハッシュ、透かしの適用状態を記録します。公式本体には公式モデルrevisionを記録し、独自本体には付けません。本体の選択時には内容のハッシュを確認するため、初回は時間がかかります。選択した本体名とハッシュは利用中のブラウザーに保存し、再読み込み後に同じ内容を確認して選択を戻します。ファイルが変更・削除されている場合は未選択と表示し、選び直してください。読み上げ文や参照音声はこの選択情報には保存しません。Forgeのモデル保持設定に従い、同じ本体・内容・精度での再生成は読み込み済みモデルを再利用します。本体や精度の切り替え、中断・失敗時は終了を確認してからGPUを返却します。「モデルを解放」でも回収できます。

日本語専用です。1回の生成は最大30秒で、長文を自動分割しません。モデルのtoken上限を超える文は短くしてください。固有名詞・難読語が誤読される場合があります。公式SilentCipherの透かし処理を維持します。利用できない場合は結果に明示します。

モデルには[Gemma利用規約](https://huggingface.co/Aratako/Irodori-TTS-v4-Large/blob/main/GEMMA_TERMS_OF_USE.md)と公式の追加条件が適用されます。本人の明確な同意のない声の複製や、誤認を誘う音声には使用しないでください。

モデル仕様と推論方法: [公式モデルカード](https://huggingface.co/Aratako/Irodori-TTS-v4-Large)、[公式実装](https://github.com/Aratako/Irodori-TTS)、[絵文字一覧](https://github.com/Aratako/Irodori-TTS/blob/main/EMOJI_ANNOTATIONS.md)。
