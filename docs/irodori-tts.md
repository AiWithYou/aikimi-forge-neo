# Irodori TTS

Irodori-TTS-v4-Largeで日本語の音声を生成します。読み上げ文だけでも、声の説明や参照音声を加えても生成できます。

## 準備

リポジトリ直下の`aikimi-irodori-setup.bat`を実行してからForge Neoを起動し、`Irodori TTS`タブを開きます。Python 3.11の専用環境へ公式コードと依存関係を導入し、モデル・tokenizer・DACVAE・SilentCipherを取得します。必要なPythonはuvで取得します。Forge本体のPython環境は更新しません。NVIDIA CUDA GPU向けです。

## 使い方

1. 日本語の読み上げ文を入力します。公式の感情・発声用絵文字もそのまま使用できます。
2. 必要なら「声の説明」に声質・感情・話し方を入力します。空欄でも生成できます。
3. 声を参照したい場合は「参照音声」を開き、使用許可のある同じ話者の音声を追加します。参照なしでも生成できます。
4. 「生成」を押し、完成した音声を再生・保存します。「中断」は停止確認後に次の生成を受け付けます。

参照は16/24/32bit PCM WAVに対応します。最大12ファイル、合計120秒までです。複数の参照は順番に別々にエンコードして結合します。公式は同じ話者の短い音声を複数使う方法を推奨しています。参照と声質の指示が矛盾する場合は、声の説明を感情や話し方に絞ってください。

詳細設定の標準値は40ステップ、テキストCFG 3、声の説明CFG 3、参照音声CFG 5です。BF16を標準とし、FP32も選べます。これは量子化設定ではありません。音声codecはFP32で動作します。長さ0は自動予測です。長さ倍率は自動予測だけに適用します。指定した長さから末尾の無音が除かれるため、完成ファイルの秒数が短くなる場合があります。

## 保存と制限

出力は`outputs/irodori/<生成ID>/`に48kHz WAV、生成条件、結果情報として保存します。このセッションの履歴から再生・ダウンロードできます。条件には実際のseed、モデル・コードのrevision、参照音声のハッシュ、透かしの適用状態を記録します。Forgeのモデル保持設定に従い、同じ精度での再生成は読み込み済みモデルを再利用します。別モデルへの切り替え、精度変更、中断・失敗時は終了を確認してからGPUを返却します。「モデルを解放」でも回収できます。

日本語専用です。1回の生成は最大30秒で、長文を自動分割しません。モデルのtoken上限を超える文は短くしてください。固有名詞・難読語が誤読される場合があります。公式SilentCipherの透かし処理を維持します。利用できない場合は結果に明示します。

モデルには[Gemma利用規約](https://huggingface.co/Aratako/Irodori-TTS-v4-Large/blob/main/GEMMA_TERMS_OF_USE.md)と公式の追加条件が適用されます。本人の明確な同意のない声の複製や、誤認を誘う音声には使用しないでください。

モデル仕様と推論方法: [公式モデルカード](https://huggingface.co/Aratako/Irodori-TTS-v4-Large)、[公式実装](https://github.com/Aratako/Irodori-TTS)、[絵文字一覧](https://github.com/Aratako/Irodori-TTS/blob/main/EMOJI_ANNOTATIONS.md)。
