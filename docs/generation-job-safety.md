# 生成中の中断とGPUの共有

Forge Neoの生成機能はGPUの使用を順番に管理します。別の生成が実行中の場合は、終了まで待機します。H3動画とH3画像は共通のComfyUIを使います。

H3の「中断」は対象の生成に停止を要求します。停止要求の受付と実際の停止は別のため、完了を確認するまでは入力ファイルとGPUの使用権を保持します。通信が途切れて受付の有無を確認できない場合も、同じ生成を勝手に再送しません。

アプリを終了したときに確認待ちの生成がある場合、再起動後にその状態を確認します。接続先が応答しないときは、生成の状態を確認するか、接続先のComfyUIを停止してください。保存済みの画像や動画は削除されません。
