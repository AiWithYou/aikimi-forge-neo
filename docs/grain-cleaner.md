# Grain Cleaner

Extras の **Grain Cleaner / 微細な粒状感を抑制** をオンにして実行します。初期状態はオフです。**Grain Cleanerだけ実行する設定にする** ボタンで、Upscale・Color Flatten・色むら確認をオフにできます。Generate付近の「実行する処理」で処理順と予定サイズを確認してください。追加の後処理拡張がある場合、この単独設定ボタンは無効です。

| 操作 | 初期値 | 用途 |
| --- | --- | --- |
| 全体強度 | 0.50 | 粒状成分の減衰量。0なら無変更 |
| 細部保護 | 0.75 | 上げると曖昧な細部も保護 |
| 色の粒の抑制 | 0.60 | 色差の減衰量 |
| 粒サイズ | 1.00 | 原寸画素を基準に0.5～2.0 |

自動モードは64×64の参考パッチが4個未満なら無変更です。見本範囲モードでは、プレビュー上の対角2点を順にクリックすると矩形が表示され、原寸の `x, y, width, height` が入力されます。縦横32画素以上、EXIFの向き補正後の座標です。画像上の選択はSingle Image・Upscaleオフ時に使えます。拡大と併用する場合やバッチでは処理後の座標を手入力してください。入力画像・入力タブ・拡大設定を変えると範囲を解除します。

処理マスクは白が処理許可、黒が変更禁止。保護マスクは白が完全保護です。画像と同寸法にしてください。アップスケールと併用する場合、マスクと見本範囲はアップスケール後の画像に合わせます。同じ指定はバッチ内の全画像に適用されます。

診断をオンにすると差分×8、減衰率、保護、参考範囲を追加出力します。結果欄は処理状態・変更画素率・所要時間を表示し、「詳細JSON」で設定と推定情報を展開できます。強度0・全面保護・参考範囲不足などで診断画像を省略する場合も理由を表示します。PNGの処理メタデータには詳細JSONを保持します。保存形式は既存の Extras 設定に従うため、画素を保った比較にはPNGを選んでください。

直近1画像の解析だけを再利用します。全体強度・細部保護・色抑制・マスク・診断表示を変えても再解析しません。画像内容・粒サイズ・推定モード・見本範囲が変わると解析し直します。別画像の読み込みや無効状態での実行時にはキャッシュを破棄します。

## CLI

リポジトリの仮想環境で実行します。出力先にはまだ存在しないディレクトリを指定します。

```powershell
venv/Scripts/python.exe -m tools.grain_cleaner input.png output/grain-run --diagnostics
venv/Scripts/python.exe -m tools.grain_cleaner input.png output/grain-sample --sample-roi 0 0 128 128 --strength 0.75
```

ディレクトリ入力はJPEG・PNG・静止WebPを1枚ずつ処理します。補正PNG、JSONログ、任意の診断PNGを保存します。`--apply-mask` と `--protect-mask` で原寸グレースケール画像を指定できます。

## 方式と制限

設計案v0.2に基づくCPU処理です。正規化Labの非間引きGaussian分解、MADによる帯域別振幅、エッジ・方向性・大振幅の点線保護を使用します。細かい2層だけを部分減衰し、Lab往復差分を元RGBへ加えます。追加モデル、外部API、新しい依存パッケージは不要です。

処理コアとCLIは8bit RGB・完全不透明RGBA、縦横64画素以上を対象とし、ICCをsRGBへ変換します。透明画像、16bit、CMYK、アニメーションは非対応です。Extrasは既存の読込処理で画像を変換する場合があるため、元ファイル形式の厳密な検査にはCLIを使用してください。

髪・反射・模様の意味を識別する処理ではありません。添付設計書の評価用9画像は未確認で、全画像での画質改善や15～35％の低減を保証しません。原寸比較で調整してください。ブラシ編集と、スライダー変更だけで補正結果を更新するライブプレビューは未対応です。
