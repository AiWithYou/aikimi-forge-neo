# 画像生成の共通画面

上部のモデルボタンから系列を選びます。画像生成ではForgeのtxt2img／img2imgと同じ順序で、チェックポイント、プロンプト、生成・中断、生成設定、結果を操作します。プロンプトと生成ボタンは上部、生成設定と入力画像は左、結果は右に配置します。

## 生成と編集

- **txt2img**：文章から新しい画像を生成します。前に使った参照画像を保持していても、このモードの生成には渡しません。
- **img2img**：入力画像と文章から編集します。Ming Image、Qwen Image 2.1、FLUX 3、H3 Imageでは、参照画像を用いるモデル固有の編集方式を使います。
- SDXL・Anima 3.8B・Krea2はForgeのtxt2img／img2imgを使います。

H3 Imageでは、P-H3 ImageとMiniMax-H3-Imageを選べます。

参照編集モデルにはForgeのdenoising strengthやサンプラーを追加しません。そのモデルで実際に調整できる項目を表示します。

Studio間の切替では、対応しているモデルに編集モードを引き継ぎます。Krea2・Animaでは、既存のForgeタブとPresetの選択に従います。

## 固有の設定

LoRA、ControlNet、透過背景、モデル詳細などは、画面上部のボタンで表示・非表示を切り替えます。閉じても選択値と有効状態は保持されます。有効にした機能はボタンに表示されるので、閉じた状態でも確認できます。

生成した画像は、対応モデルでは**img2imgへ送る**から次の編集に使えます。生成条件とダウンロードは結果の下にあります。モデルの切替だけでは画像生成やモデルのダウンロードは始まりません。

Outpaint、動画、音楽、画像評価はそれぞれの専用画面を使います。

ギャラリーで画像・動画・音声を検索し、作品のプロンプトをプロンプト集に保存できます。プロンプト集では `{朝|夕暮れ}` のような選択肢を Seed で展開し、開いているスタジオに挿入できます。一覧・プレビュー・お気に入り・隔離の対象は生成結果です。Forge の init-images を含む入力画像、各スタジオが保存する参照入力、作業中のファイルは対象外です。H3 Image へ送ると、作品を生成したモデルのタブが開き、そのプロンプト欄に入力されます。お気に入りは★で切り替えます。隔離した作品は tmp/aikimi-gallery/quarantine に保存されます。

ナビゲーションの「プロンプト集」または Alt+P でテンプレートを開きます。「展開」に使った Seed は再利用できます。ギャラリーで作品を選ぶと生成条件を確認でき、画像は img2img や Extras に送れます。

隔離した作品を戻すには、`tmp/aikimi-gallery/quarantine/` の各フォルダーに残る `output/` または `outputs/` 以下の位置を確認し、元の出力フォルダーへ移動して「検索・更新」を押します。
