# 画像生成の共通画面

上部のモデルボタンから系列を選びます。画像生成ではForgeのtxt2img／img2imgと同じ順序で、チェックポイント、プロンプト、生成・中断、生成設定、結果を操作します。プロンプトと生成ボタンは上部、生成設定と入力画像は左、結果は右に配置します。

## 生成と編集

- **txt2img**：文章から新しい画像を生成します。前に使った参照画像を保持していても、このモードの生成には渡しません。
- **img2img**：入力画像と文章から編集します。Qwen Image 2.1、FLUX 3、SenseNova、H3 Imageでは、参照画像を用いるモデル固有の編集方式を使います。Irisでは変更強度を指定して通常サンプリングで描き直します。
- Krea2・AnimaはForgeのtxt2img／img2imgを使います。Ming・Nanosaur2は現在txt2imgに対応しています。

参照編集モデルにはForgeのdenoising strengthやサンプラーを追加しません。そのモデルで実際に調整できる項目を表示します。Irisでは学習に対応するサイズから選択します。

Studio間の切替では、対応しているモデルに編集モードを引き継ぎます。Krea2・Animaでは、既存のForgeタブとPresetの選択に従います。

## 固有の設定

LoRA、ControlNet、透過背景、モデル詳細などは、画面上部のボタンで表示・非表示を切り替えます。閉じても選択値と有効状態は保持されます。有効にした機能はボタンに表示されるので、閉じた状態でも確認できます。

生成した画像は、対応モデルでは**img2imgへ送る**から次の編集に使えます。生成条件とダウンロードは結果の下にあります。モデルの切替だけでは画像生成やモデルのダウンロードは始まりません。

Outpaint、動画、音楽、画像評価、Irisの深度推定・復元はそれぞれの専用画面を使います。
