# CD Tuner・MiniMax H3 NegPiP

2つの原作拡張を、それぞれの実行経路へ統合しています。**どちらも既定ではオフ**です。追加モデルのダウンロードや、無関係なComfyUI拡張の有効化は行いません。

## CD Tuner — 通常の画像生成

`txt2img` / `img2img` の **CD Tuner** を開いて有効にします。まず同じモデル・プロンプト・Seedで、1項目ずつ小さい値から比較してください。CD Tunerは生成過程の調整で、Extrasの画像後処理ではありません。H3 / SenseNovaの別プロセスのStudioには作用しません。

- **Detail / Detail 2**: 入出力層の重みを調整。Hires用の値と停止Stepも指定できます。
- **Contrast / Brightness / Color / Saturation**: 生成中の重み・潜在表現・VAEの調整。項目ごとに作用する場所が異なります。
- **Color Map**: 分割した領域へ色を指定。色は `R,G,B` または `明るさ,R,G,B`、複数色はセミコロンで区切ります。1色だけなら全領域に共通適用し、複数色では領域数と一致させてください。

停止Step `-1` は停止指定なしです。`Apply once` は同一生成リクエストの最初のバッチだけに適用します。設定はPNG Infoの `CDT` / `CDTC` に保存され、原作の `<cdt:...>` / `<cdtc:...>` 構文を引き続き利用できます。バッチ内で共通の重みを使うため、同一バッチの先頭プロンプトの指定を使用します。

### モデルの制約

原作のSD / SDXL、Flux / Chroma、Z-Image、Anima、Krea2向けの層選択・潜在色変換を継承しています。ただし、モデル名が対応していても、その量子化形式まで検証済みという意味ではありません。

**整数の量子化重みそのものは直接書き換えません。** 未対応の量子化層を編集しようとすると、当該処理を停止し、既に編集した層を復元します。Detail・Contrast 1・Saturationを0に戻して比較してください。潜在表現だけに作用する色・明るさの設定は別経路です。極端な値では色・構造が崩れる場合があります。未知のモデル構造での適用は保証しません。

### Aikimi側の変更

原作の独自GradioウィジェットとJavaScriptを、既存のForge UI部品へ置換しました。旧式のUI設定ファイル直接書き換えボタンは使用せず、通常のUI設定保存を使用します。同じ名前の外部 `sd-webui-cd-tuner` があっても、Forgeの重複拡張検出により同梱版を優先します。別名へ変更した外部コピーは無効化してください。

生成終了・キャンセル・例外時の既存 `on_process_cleanup` に重み復元を接続しています。変更対象の実モジュールを記録するため、参照先モデルが切り替わっても元の対象を復元します。バックアップはCPUへ置き、完了後に解放します。txt2img / img2img間で有効なコールバック状態を残しません。GPU自体の故障などで復元に失敗した場合は、エラーを表示してモデルの再読み込みを案内します。

5次元潜在表現のHires判定、現在のバッチのプロンプト参照、数値・領域数の検証、無調整の層への不要な書き込みも修正しています。Color Mapの生成処理ではプレビュー画像を作らず、プレビューの配色は生成用乱数を消費しません。

## MiniMax H3 NegPiP — 動画と静止画

`H3 Studio` / `H3 Image` の **NegPiP · プロンプト内の負の重み** を開き、「NegPiPを有効にする」をオンにします。動画タブでは高速化の設定欄の下にあります。

有効・無効を切り替えたら、生成キューを空にして **実行環境とモデル → 選択設定で再起動** を押してください。Forgeが管理していない外部起動のComfyUIは勝手に停止しません。その場合は元のランチャーで停止してから、このタブの接続・起動を使用します。

有効時だけ、選択したローカルComfyUIの次のフォルダーへ、リポジトリに同梱した固定版をコピーします。

```text
ComfyUI/custom_nodes/Aikimi-MiniMax-H3-NegPiP/
```

ネットワークからコードを取得せず、同梱ファイルを固定のGit blobハッシュと照合します。既に同じ版があれば再コピーしません。既存の内容が異なる場合やリンクされた導入先には上書きせず停止します。管理フォルダーを独自に編集した場合は、その内容を別の場所に保管してから当該フォルダーを取り除き、再起動で同梱版を再配置してください。

`--disable-all-custom-nodes` は維持し、選択したNegPiPと、使用時のFast VAEだけを許可します。原版を別フォルダーにインストールする必要はありません。既存の原版コピーはこの管理起動では許可しないため、同じノードを二重に読み込みません。

### プロンプト例

```text
An apple on the table, daytime. (red fruit:-1.0)
```

負の語句を本文から取り出して別にエンコードし、その語句のAttention Valueを反転します。通常のネガティブプロンプト欄や単純な埋め込みの倍率とは異なります。`value_strength = 1` はプロンプト内の指定どおりの倍率です。まず `-1` から比較し、強くする前に `red` を `red fruit` にするなど対象を含めた表現を試してください。強い負の重みで逆効果になる場合は「テキスト行を保護」を比較できます。

動画の時間指定は原作の構文をそのまま渡します。

```text
A rainy city street at night. (neon signs, neon lights:-1.5@v2.5-4.0)
```

`@v` は映像だけ、`@a` は音声だけ、区別なしは両方です。開区間も使用できます。時間指定の効果は実験的で、追加のAttention呼び出しにより遅くなる場合があります。H3 Imageは内部5フレームなので、時間指定なしで比較してください。

有効時は正の強調構文も解釈されます。文字として括弧を出す場合は `\(` / `\)` とエスケープしてください。`embedding:` の負の重みは原作で未対応です。

### 接続・互換性

NegPiPのMODEL出力をGuiderとSchedulerへ、CLIP出力をH3 conditioningノードへ接続します。テキスト動画・キーフレーム動画・参照動画・静止画・参照画像編集の各経路に対応します。無効時はノードを追加せず、従来のグラフを維持します。

**Sparse Attentionとの同時使用は未検証のため拒否します。Kitchen denseで使用してください。** Fast VAEとは別の処理段階で、両方を選択した場合も許可するノードをその2つに限定します。モデルの再学習や重みファイルの恒久的な改変は行いません。

動画履歴では既存の `acceleration` 設定内の `negpip` に保存・復元します。過去の履歴にこの項目がなければオフになります。静止画は `parameters.json` の `negpip` に保存します。

## 検証範囲

CPUテストで、設定の境界値・旧履歴互換・全モードのMODEL/CLIP接続・無効時のグラフ不変・許可リスト・固定版導入・UI入出力数・CD Tunerの重み復元と5D Hires処理を確認する構成です。

**実モデルを使ったGPU生成、画質、速度、ピークVRAMはこの統合のCPUテストでは確認できません。** 実機では同じSeedでオフ→オン→オフの順に比較してください。CD Tunerの終了後とNegPiP無効時に従来の生成へ戻ること、キャンセル後に次の生成が正常に動くことも確認対象です。
