# Forge Neoとの同期

v7.0.0の比較基準は `upstream/neo` の `6d5aa3bc0c9316a0764a4b61ea76835fb4d82fb1` です。

- txt2imgまたはimg2imgのJSON Builderで領域を配置し、各領域と画像全体の説明を入力します。「MOSS Image のプロンプト欄へ送る」を押すと、MOSS Imageタブが開き、レイアウトと画像サイズが入力されます。
- オンラインパッチを使うLoRAでは `<lora:name:[0@0,1@0.5,0.5@1]>` のように強度と進行率を指定します。Euler では最初のモデル評価を進行率0、最後を1として直線補間します。1ステップの場合は開始時の強度を使います。
- バッチ内ではモデルの重みを共有するため、全プロンプトに同じステップ指定を使います。指定が異なるバッチはステップ別LoRAを省いて生成します。X/Y/Z plotの「Prompt S/R (LoRA)」で異なるスケジュールを比較するときは、各セルに一つずつ指定します。値にカンマを含む場合は、値全体をダブルクォートで囲みます。
- SolAttnは対応するCUDAデバイスとcomfy-kitchenで自己注意の一部を高速化します。Dense Blocks は0〜256の番号と昇順の範囲をカンマで区切って指定します。最大128区間、重複を含む展開数は512までです。Spectrumは一部ステップの出力を予測します。Hires では2回目のステップ数を使い、0なら通常のステップ数を引き継ぎます。速度と画質は画像サイズと設定で変わります。
- ExtrasのDeGridは規則的な格子模様を抑えます。Thresholdの0は自動設定です。RGBA画像の透明度は保持します。
- SLGは負条件の計算で指定層を飛ばします。MOSS Image Studioの既定は第22層、進行率0〜1です。対象層や適用範囲は設定から変更できます。
- X/Y/Z plotはLoRAや追加モジュールを軸に選べます。モデル一覧の更新で追加ファイルを再検出します。参照画像はモデルの入力条件に合わせてリサイズします。幅と高さの手入力はResolution Stepに合わせて丸めます。
- Extensions画面で導入済み拡張の状態を確認できます。チェックポイントに追加モジュールの選択を保存できます。
- 拡張のインストール先にはフォルダー名を一つ指定します。拡張管理を無効にした起動設定では、インストール、カタログの取得、構成バックアップの保存を制限します。
- GGUFの読み込みにはgguf 0.19.0を使用します。対応するCUDA環境では `--enable-triton-backend` でK-QuantのTriton復号を有効にできます。未対応の形状、Triton未導入、CPUの場合はPyTorchで復号します。NVFP4の復号、Attention精度、条件のバッチ処理を更新しました。`--force-w4a8` は対応するConvRotモデルの活性化を8ビットに指定します。
- `--disable-preset anima krea` は指定したプリセットを非表示にします。`--sort-preset` は名前順に表示します。
