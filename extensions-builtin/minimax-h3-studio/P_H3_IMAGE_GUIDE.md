# P-H3 Image

P-H3 ImageはMiniMax H3をもとに作られた、静止画の生成・編集モデルです。`H3 Image`から、テキスト生成と最大8枚の画像を使う編集を選べます。従来のH3の5フレームを使った実験モードも選択できます。動画向けの`H3 Studio`は従来どおり利用できます。

## はじめに

初回は`H3 Image → P-H3 Image → 準備を開く`を選び、`環境とモデルを準備`を押します。実行環境はH3動画と共通で、画像生成だけなら動画用モデルは不要です。Windows、NVIDIA GPU、Git、インターネット接続が必要です。標準構成はW4A8本体・W4A8テキストエンコーダー・INT8 VAEで、プロンプト補助用INT8モデルも取得します。モデルだけで約29.8 GB、別途実行環境とダウンロード中の空き容量が必要です。

P-H3画面の導入状態は、必要ファイルの存在に基づく簡易確認です。生成時には対応ノードやモデルを改めて確認します。プロンプト補助のモデルがない場合は、その機能をオフにして使えます。

標準の保存先は`models/MiniMax-H3`で、P-H3用のファイルを次の場所に配置します。ComfyUIの固定版とPythonは新しい実行環境に準備し、既存のH3環境は新環境の確認が終わるまで保持します。共通実行環境はComfy Compilerをオフにして起動します。

| 種類 | 標準ファイル |
|---|---|
| 本体 | `diffusion_models/p-h3-image_w4a8.safetensors` |
| テキストエンコーダー | `text_encoders/p-h3-image_text_encoder_w4a8.safetensors` |
| VAE | `vae/p-h3-image_vae_int8_convrot.safetensors` |
| プロンプト補助 | `text_encoders/p-h3-image_prompt_upsampler_int8_convrot.safetensors` |

モデルの利用条件は[配布元のモデルカード](https://huggingface.co/PrunaAI/P-H3-Image-Comfy)と[MiniMax H3 Community License原文](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/LICENSE)を確認してください。主な条件は次のとおりです。

- EU、英国、韓国、米国はライセンスの適用地域から除外されています。これらの地域でのモデルや生成物の利用は、この契約では許諾されません。
- 商用製品・サービスの年間売上が2,000万米ドルを超える場合は、MiniMaxから事前の書面による許諾が必要です。
- 商用製品・サービスの画面には「MiniMax H3」の表示が必要です。原文は「Powered by MiniMax H3」の表示を推奨していますが、P-H3のモデルカードはこの表記を必須と説明しています。
- モデル等を第三者へ配布する場合は、契約書の提供や、ホスティング以外の配布における指定NOTICEなどの条件があります。配布形態に応じて原文を確認してください。

## 生成と編集

1. `H3 Image`で`P-H3 Image`を選び、プロンプトと画像サイズを指定します。
2. 画像を編集するときは編集対象を1枚追加します。さらに参照画像を最大7枚追加でき、表示順に`<Picture 2>`から`<Picture 8>`に対応します。参照の順番は画面で変更できます。編集対象は`<Picture 1>`です。
3. 必要に応じてプロンプト補助を使い、生成を開始します。オフにすると補助用モデルを使わず入力文から生成します。短い指示では補助を使う方がよい場合があります。
4. 完成した画像と生成条件は自動保存されます。Seedを指定すると、同じ条件を再利用する際の出発点になります。

出力はデータフォルダーの`outputs/minimax_h3/p_h3_images/`へ保存します。`--data-dir`を指定した場合は、そのフォルダーを使います。

生成前に選択した本体の内容を確認します。初めて使う大きなモデルは確認に時間がかかり、その間も中断できます。確認が終わるまでGPUでの生成は始まりません。

P-H3は8ステップ、Euler、CFGなしで生成します。公式はテキスト生成に約8 MP、編集に約4または8 MPを推奨しています。大きな画像や複数参照はメモリと処理時間を多く使うため、まず小さなサイズで動作を確かめてから上げてください。8 MP推奨サイズの例は正方形2912×2912、横長16:9なら3872×2176です。カスタムサイズは各辺32〜16384ピクセルの32の倍数を指定できます。大きなサイズでの完走は保証されず、16 MPを超える設定は公式モデルカードの掲載例の範囲外です。

生成と編集を切り替えても、それぞれの画像サイズは画面を開いている間保持されます。画面の初期値を保存した場合は、次回の表示内容とサイズ要約にも反映されます。

編集対象は入力画像の縦横比を保って約4 MPへ拡縮し、モデルへ渡します。画面のサイズ指定は出力画像の大きさです。元のファイルは変更しません。

## 対応モデル

標準のP-H3 Image本体に加え、同じ構造を持つ本体を選択できます。BF16、INT8、W4A8を含めて構造を確認しますが、構造が一致しても品質や生成結果の互換性は保証できません。従来のMiniMax H3動画本体とは区別されます。テキストエンコーダーとVAEはP-H3用を使います。

MiniMax H3のFL2VA本体にP-H3用LoRAを重ねる公式方式は、この画面では未対応です。P-H3互換構造の本体を選択してください。

## 制限

入力画像の人物・文字・構図を完全に保持できるとは限りません。画像が小さいほど顔や手などに破綻が出やすく、長い文章や小さな文字の描画にも誤りが生じる場合があります。W4A8の出力はBF16と同一ではありません。生成時間、画質、ピークVRAMはハードウェアや設定によって変わります。

モデルや実行環境を準備しただけでは生成を実行しません。
