# MiniMax H3 Image

`H3 Image`タブで、MiniMax H3を使ったテキストからの画像生成と参照画像による編集を行います。既存の`H3 Studio`動画タブは変更しません。

これは**標準H3モデルの最小5フレームを使う、実験的な静止画モード**です。完成動画から画像を取り出す処理ではありません。H3の映像・音声を組み合わせた潜在表現を生成し、画像だけを復号してPNGへ直接保存します。音声の復号とMP4の作成は行いません。専用画像モデルと同じ処理量・画質を保証するものではありません。

## 必要な環境

[H3 Studioの初回セットアップ](README.md#初回セットアップ)を実行してください。画像・動画でNeo内の同じ実行環境と標準H3モデルを使います。画像用の追加モデルは不要です。

| 用途 | 使用モデル |
|---|---|
| テキストから画像生成 | `minimax_h3_fl2va_pruned_int8_convrot.safetensors` |
| 参照画像による編集 | `minimax_h3_ref2va_pruned_int8_convrot.safetensors` |
| 共通テキストエンコーダー | `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors` |
| 画像の復号・参照画像の符号化 | `minimax_h3_video_vae_fp16.safetensors` |
| 共通環境の検証・旧参照ノードとの互換 | `minimax_h3_audio_vae_fp32.safetensors` |

既存の環境検証をそのまま使うため、テキスト生成でも標準H3 Studio一式の導入が必要です。音声VAEが存在していても、画像ワークフローで音声を復号・保存することはありません。

ComfyUIの`SaveImage`と`ImageFromBatch`も生成前に確認します。外部有料APIは呼びません。接続先はローカルHTTPのみで、既存のプロセス識別、モデル確認、起動設定、公開制限を維持します。

## 使い方

1. Forgeを更新して再起動し、`H3 Image`タブを開きます。上部の`MiniMax H3`ショートカットは従来の動画タブを開くため、画像生成では`H3 Image`を選んでください。
2. 初回だけ`H3 Studio`の`環境とモデルを準備`を実行します。準備済みなら、この操作は不要です。
3. `テキスト → 画像`を選び、完成させたい静止画のプロンプトを入力します。
4. 最初は`動作確認 · 512×512`または`正方形 · 768×768`を選び、Stepsは標準の20のままにします。
5. `画像を生成`を押します。停止中の管理対象ComfyUIは、生成操作時に起動します。

### 参照画像で編集する

`参照画像から編集`へ切り替え、1〜9枚をアップロードしてください。アップロード順に`<Picture 1>`〜`<Picture 9>`が割り当てられます。使わない画像は取り除き、残した全画像の役割をプロンプトへ書きます。

```text
<Picture 1>の人物、顔、髪型、ポーズ、構図を保ち、服だけを<Picture 2>の衣装へ変更する。完成した1枚の静止画として描く。
```

このモードはRef2VAによる再生成です。元画像をそのまま貼り付ける処理ではなく、画素・顔・構図の完全保持は保証しません。FL2VAの開始フレーム固定ではないため、入力画像をそのまま完成画像として返す仕組みにもしていません。

### 解像度・Seed・候補

幅と高さは256〜2048の範囲で、それぞれ32の倍数を指定します。約1MPを超える直接生成は実験的です。H3-Regenerate-2Kではありません。解像度を上げると処理量とメモリ消費が増え、細部の改善は保証されません。

Seedは`-1`でランダムです。実際に使用した整数は生成条件に保存されます。大きなSeedを丸めないように、入力欄はテキスト形式です。

標準では候補0を採用します。`詳細設定`で採用フレームを0〜4から選べます。`5候補もPNG保存して比較する`を有効にすると全候補を確認できます。**5候補は同一時間系列のフレームであり、独立した5シードのバッチではありません。**

## 保存と停止

結果は毎回、新しいフォルダーへ保存します。

```text
outputs/minimax_h3/images/H3_Image_<日時>_<識別子>/
  image.png
  parameters.json
  candidate_00.png ... candidate_04.png  # 候補保存を有効にした場合
```

PNGとJSONは画面から取得できます。JSONにはプロンプト、解像度、Steps、確定Seed、モデル名、採用フレーム、ComfyUIの版・リビジョンなどを記録します。参照画像の絶対パスはJSONへ記録しません。ただしPNGにComfyUIのプロンプト情報が含まれる場合があります。共有前に内容を確認してください。

保存時はPNGの形式・解像度を検査します。すべてのファイルを書き終えるまで結果フォルダーを公開しないため、途中の結果を完成扱いしません。入力画像や既存結果は上書きしません。

`停止`はその画像ジョブだけに作用します。画像と動画は同じH3生成キューを使い、結果保存中の管理対象ランタイム再起動も拒否します。停止確認前に、使用中の一時参照画像を削除しません。

## 対応範囲と検証

この画像タブは、標準INT8 ConvRotモデル、通常の動画VAE、Dense Attentionを使用します。動画タブの設定は書き換えません。別の設定でComfyUIが動いている場合は、キューを空にして画像タブの`選択設定で再起動`を使います。このForgeが起動していない外部プロセスは自動停止しません。

Single-frame Image VAE、Turbo・LightX用LoRA、Hybridチェックポイント、Fast VAE、Sparse Attentionは、この画像タブではまだ扱いません。これらを標準モデルの代わりに黙って読み込む処理もありません。

追加したCPUテストは以下で実行できます。ワークフロー、入力検証、参照タグ、PNG保存、保存先制限、停止、再試行、Gradioの部品構築を確認します。

```powershell
.\venv\Scripts\python.exe -m unittest -v tools.tests.test_minimax_h3_images
```

実装時はPython 3.13の部分作業環境で30件中29件が成功し、完全なForge環境を必要とする1件は未実行でした。Gradio 6.5.1で部品構築を確認しています。ブラウザーの実描画は検証環境のアクセス制限で未確認です。Windows上のForge全体、対象Gradio 6.17.3、実モデルを用いたGPU画像生成、生成画質・速度・ピークVRAMは未検証です。

## NegPiP（任意）

プロンプト内の負の重みを使用できます。既定はオフで、有効・無効の切替後は「選択設定で再起動」が必要です。[使い方と制約](../../docs/cd-tuner-negpip.md)を参照してください。
