# Clef

画像・文章・JSONデータに共通の質問セットを適用し、選択肢・段階評価・真偽の確率を確認するローカルの専用画面です。Forge上段のモデル列で **YuE2 Music** の右にある **Clef** を開きます。

```powershell
.\aikimi-clef-setup.bat
.\aikimi-launch.bat
```

初回は専用Python環境と、Hugging Faceの [Flash INT8](https://huggingface.co/Aikimi/clef-flash-int8)（約12.17GB）/ [Clef NF4](https://huggingface.co/Aikimi/clef-nf4)（約18.85GB）から量子化済みの配布を取得します。公開配布なのでHugging Faceへのログインは不要です。検証したcommitを固定し、ダウンロード後にサイズ・SHA-256を確認します。判断ヘッド・語彙行列・画像処理設定も含み、公式の元重み約74GBは不要です。Flashだけなら `--model clef-flash`、環境だけなら `--runtime-only`、導入予定の表示は `--dry-run` を付けます。

この環境では専用Python環境と量子化配布をH:の `models/Clef/` に保存します。通常版24GB・16GBは同じNF4配布を共有します。同じモデルをGPUへ保持している間は、GPU本体を再読み込みしません。解放・切り替え・再起動後の読み込み時間はH:のI/OとOSキャッシュによって変わります。比較用Flash BF16は `--source --model clef-flash` を明示した場合に公式から取得します。

1. 入力欄の **画像 / 文章 / JSONデータ** を選びます。文章とJSONは初期状態で全体を1件として判定し、まとめて処理したい場合だけ区切り方を変えます。
2. 共通の **質問セット** でテンプレートを適用するか、フォームで質問と選択肢を編集します。判定対象の **JSONデータ** と判定基準の **質問セットのJSON** は別の欄です。
3. 入力件数と質問数を確認し、**実行モデル** を選び **N件を判定**。
4. **この実行の確率で絞る** で複数の条件を並べて指定し、**候補だけ** に絞れます。条件変更ではロード表示や再推論を行わず、各行の対象・確率を保持します。
5. 画像を選んで確率を確認し、人が採用した画像を別フォルダ・ZIPへコピーできます。JSONには実行条件と全確率、CSVには仕分け一覧が入ります。

**画像** の **生成設定を取り出す** では、画像に残るComfyUIのworkflow／prompt JSONを取得できます。文章の一括処理は **1行1件 / 空行区切り**、JSONは **配列の要素ごと / JSONL** を選びます。JSON配列を自動分割しません。タブを切り替えても入力と質問を保持し、結果・履歴も共通です。切り替えだけではモデルを読み込みません。動画入力は未対応です。

軽量版は **Flash INT8**、通常版は **Clef NF4 · 24GB** または **Clef NF4 · 16GB**。Flash BF16は量子化との差を見る比較用です。モデルは切り替え時に読み直し、同じモデルでの連続判定は保持設定に従って再利用します。

判定記録は実行時の入力を保持します。設定変更後は **現在の入力と不一致** と表示し、前回の結果を書き換えません。同一画像・同一判断項目・同一補足入力・同一処理解像度の記録同士を比較できます。

Forge全体を立ち上げずに同じ画面を使う場合:

```powershell
.\venv\Scripts\python.exe tools\run_clef_studio.py
```

[http://127.0.0.1:7862](http://127.0.0.1:7862) を開きます。推論は専用環境を使います。[仕様・量子化・検証範囲](../../docs/clef-studio.md)
