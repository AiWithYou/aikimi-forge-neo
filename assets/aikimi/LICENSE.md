# ちびあいきみ画像の利用条件

適用日：2026年9月10日。利用許可の窓口：AiWithYou。

## 対象

この条件は、このフォルダーにあるPNG・WebP形式のちびあいきみ画像に適用します。コード、画像生成・加工ツール、`manifest.json`には適用せず、それらの既存ライセンスを変更しません。

ちびあいきみはAiWithYouとAikimi Studio Neoを表すブランド素材です。汎用のフリー素材として提供するものではありません。AiWithYouが許諾できる権利の範囲で、次の利用を認めます。

## 個別許可なしで利用できる範囲

- Aikimi Studio Neoの実行に伴う画像の表示。
- 本ソフトとそのforkへの画像の同梱・再配布。この利用条件と出典表示を保持し、本ソフト由来の表示に使用してください。改変版はAiWithYouの公式版・公認版と誤認されないようにしてください。
- ソフトの紹介、レビュー、操作説明、不具合報告に伴うスクリーンショット・動画への掲載。収益化した記事や動画も含みます。
- 上記の表示・掲載に必要な拡大縮小、形式変換、レイアウト上の切り抜き。
- GitHubの利用規約に基づく閲覧とforkに伴う複製。

ソフト内で元の表示を維持する場合やスクリーンショットを掲載する場合、画像上への追加クレジットは不要です。画像を同梱して配布する場合は、この文書を保持してください。

## 個別許可が必要な利用

- 自分や第三者のSNSアイコン、ロゴ、アバターとしての使用。
- 別の製品・サービス・ソフトの看板、キャラクターとしての使用。
- 画像を取り出した素材配布、画像集への収録、素材販売。
- 上記の表示調整を超える改変画像の配布、別のキャラクターへの流用。
- グッズ化、商品化、ソフトの紹介を目的としない広告への使用。

相談先は[AiWithYouのGitHubプロフィール](https://github.com/AiWithYou)です。許可を得るまで、上記の利用は行わないでください。

## ブランドと既存の権利

この条件は、AiWithYou本人を名乗ることや、公式・公認・提携・推奨を示すことを許可しません。プロジェクト名を紹介や出典の説明に使うことは認めます。

コードのAGPL-3.0による利用・改変・再配布を制限するものではありません。キャラクター画像を除外してソフトを配布することもできます。

法令上認められる利用、GitHubの利用規約による権利、過去に有効に付与されたライセンス上の権利を、この条件で取り消したり狭めたりするものではありません。過去の画像に本条件が遡って優先するとは主張しません。
